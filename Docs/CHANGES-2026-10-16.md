## Added

- `Services/ScaleOptions.cs`: the `Scale` settings section (see README, "Scale Integration").
- `Services/WeightCache.cs`, `Controllers/WeightApiController.cs`: `POST /api/weight`, protected by `X-Api-Key`, fails closed when no key is set.
- `Services/AgentScaleService.cs`: real `IScaleService` reading the cache; data older than 5 s is "No signal".
- `Program.cs`: mock in Development, real scale elsewhere; refuses to start with the mock outside Development.
- `EdgeAgent/`: Windows Worker Service that reads the indicator's serial port and posts weights.
- Frontend: Save buttons enabled only for a stable, non-zero weight; live weight refreshes every 500 ms.

## Not changed (need a decision or the real hardware)

- E10 "No print" checkbox: still not read by the server. Needs a decision on what it should do.
- E11 `EnsureCreatedAsync()`: switch to migrations once SQLite vs SQL Server is decided for production.
- E12 `UseHttpsRedirection()`: add once the server has a certificate.
- E13 Business scenario and design PDFs: wording fixes are listed in the guide.
- `ZeroToleranceKg` (0) and `MinWeightKg` (100) are placeholders until the scale division is known.
- `IndicatorParser` handles the simulator's formats; check it against a real indicator sample.

## How to verify

```bash
rm -f truckmate.db truckmate.db-shm truckmate.db-wal
dotnet run -- --selftest            # every line [PASS]
cd EdgeAgent && dotnet build        # agent builds
```

Then follow Steps 13 and 19 of the guide (simulator straight to the API, then through a virtual serial pair to the agent).
